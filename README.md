# Java俄罗斯方块游戏

一个功能丰富的Java Swing实现的俄罗斯方块游戏，具有多种游戏模式、道具系统、排行榜和存档功能。

## 项目概述

这是一个基于Java Swing开发的俄罗斯方块游戏，作为Java课程设计项目开发。游戏具有完整的图形界面和丰富的游戏功能，支持多种游戏模式、道具系统、排行榜记录和游戏存档功能。

## 功能特性

### 🎮 游戏功能
- **经典俄罗斯方块玩法** - 支持标准的俄罗斯方块游戏规则
- **多种游戏模式** - 普通模式、时间模式、速度模式
- **道具系统** - 随机生成和使用各种游戏道具
- **实时计分** - 显示当前分数、等级、消除行数
- **下一个方块预览** - 显示即将出现的下一个方块

### 💾 系统功能
- **游戏存档/加载** - 支持游戏状态的保存和恢复
- **排行榜系统** - 记录不同模式下的最高分数
- **暂停/继续** - 游戏过程中可以暂停和继续
- **游戏设置** - 可调整游戏难度和参数

### 🎯 游戏模式
1. **普通模式** - 经典俄罗斯方块玩法
2. **时间模式** - 在限定时间内获得最高分
3. **速度模式** - 随着时间推移速度逐渐加快

## 安装和运行

### 环境要求
- Java 21 或更高版本
- Maven 3.6 或更高版本

### 编译和运行

1. **使用Maven编译**
   ```bash
   cd javatetris
   mvn clean compile
   ```

2. **运行游戏**
   ```bash
   mvn exec:java -Dexec.mainClass="org.example.TetrisGame"
   ```

3. **打包为JAR**
   ```bash
   mvn clean package
   java -jar target/javatetris-1.0-SNAPSHOT.jar
   ```

### 直接运行（如果已有JAR文件）
```bash
java -jar javatetris.jar
```

## 游戏规则

### 基本规则
1. 方块从顶部落下，玩家可以控制方块的移动和旋转
2. 当一行被完全填满时，该行会被消除，玩家获得分数
3. 游戏结束条件是方块堆叠到顶部

### 计分规则
- 消除1行：100分 × 当前等级
- 消除2行：300分 × 当前等级
- 消除3行：500分 × 当前等级
- 消除4行：800分 × 当前等级

### 等级系统
- 每消除10行提升一个等级
- 等级越高，方块下落速度越快
